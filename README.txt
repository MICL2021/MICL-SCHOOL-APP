MICL SCHOOL APP — DEMO
========================
School: Modern Institute of Creative Learning (MICL)

This is a responsive mobile/PWA prototype matching the requested MICL design.
Files:
- index.html: complete app interface
- manifest.json: installable PWA manifest
- sw.js: basic service worker
- icon.svg: app icon

How to use:
1. Open index.html in Chrome/Edge.
2. Enter any Student ID and Password on the demo login.
3. Use the buttons to navigate.

Important:
This prototype uses sample data. To make it a production school app, connect it to a secure backend/database for real student accounts, attendance, notices, homework, results, push notifications, and teacher/admin controls.
